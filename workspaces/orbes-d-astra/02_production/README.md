# Orbes d’Astra V2 — production

Ce dossier reçoit uniquement les éléments qui ont franchi la préproduction.

## État du lot vertical slice

1. `Mira` : blockout 3D et round-trip moteur en cours.
2. `Brann`, `Aster` : attente du retour sur le personnage étalon.
3. `Léviathan`, `Port noyé` : attente de la validation d’échelle.
4. Chambre de fusion et combat : prototype Godot après import du GLB étalon.

Le mot **blockout** signifie volume, silhouette, rig et métriques vérifiables. Il
ne signifie jamais modèle final ou commercialisable.
