# Vision Ellipse

## Mission

**Démocratiser la création de jeux vidéo** en permettant à toute personne — créateur de contenu, éducateur, artiste, entrepreneur — de produire des jeux 2D ou 3D haute définition **sans compétence en programmation**, en s'appuyant sur l'intelligence artificielle et des photos comme matière première.

---

## Proposition de valeur

### Pour le créateur sans code
- Décrire un jeu en langage naturel : *« Un platformer rétro avec un chat ninja »*
- Importer des photos : personnage, décor, objet → assets de jeu automatiques
- Itérer par conversation : *« Plus de particules », *« Ajoute un double saut »*
- Publier en un clic (Web, Windows, mobile)

### Pour le créateur visuel
- Style cohérent imposé par référence visuelle (photo, moodboard)
- Éditeur visuel pour ajuster sans toucher au code
- Preview temps réel pendant la génération

### Pour les studios / pros
- Prototypage ultra-rapide (vertical slice en heures)
- Pipeline reproductible et versionné
- Export vers moteurs standards (Godot, Unity) — phase ultérieure

## Différenciation vs concurrence

| Concurrent / approche | Limite | Ellipse |
|----------------------|--------|---------|
| Constructeurs no-code (GDevelop, Buildbox) | Assets et logique manuels | Génération IA bout-en-bout |
| ChatGPT + « fais-moi un jeu » | Code fragile, pas jouable | Moteur dédié + agents spécialisés |
| Génération d'images seule (Midjourney…) | Pas de gameplay | Pipeline complet jusqu'au .exe |
| Roblox / Dreams | Écosystème fermé, courbe d'apprentissage | Open pipeline, photo-to-game natif |

## Cas d'usage ambitieux (cibles Phase 4+)

1. **Photo de votre chien → jeu d'aventure** — Le chien devient héros riggé ; votre salon devient niveau 1.
2. **Carte postale de voyage → RPG exploration** — Style visuel extrait ; quêtes générées contextuellement.
3. **Selfie + prompt → fighting game** — Portrait stylisé, moveset procédural, arène générée.
4. **Classe entière → escape game pédagogique** — Enseignant upload 10 photos ; Ellipse produit le jeu clé en main.

---

## Principes UX

1. **Conversation first** — La barre de prompt est le centre de l'interface.
2. **Show, don't tell** — Chaque action d'agent est visible (timeline, miniatures).
3. **Undo everywhere** — Historique versionné par agent et global.
4. **Progressive disclosure** — Mode « Simple » par défaut ; « Pro » pour affiner.
5. **Fail gracefully** — Si un agent échoue, la maîtresse propose une alternative.

## Nom et identité

**Ellipse** évoque :
- Une orbite — les agents gravitent autour de la vision utilisateur
- Une forme fermée — un jeu complet, pas un fragment
- L'éclipse — la lumière (créativité) masque la complexité technique
